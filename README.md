# Cotizador tiivo sneakers

Mini web app para calcular el total de un pedido de lavado de tenis
según el servicio, la cantidad y el canal de entrega. Está pensada
para usarse desde el celular mientras se conversa con un cliente por WhatsApp.

## Qué hace

- Elige el servicio y la cantidad de piezas.
- Elige el canal de entrega (punto de venta o delivery en Puebla).
- Calcula el total y genera un resumen listo para copiar y pegar en WhatsApp.

Delivery en Puebla: +$40 por pedido. Entrega en punto de venta: sin costo.

## Cómo cambiar los precios

Abre `index.html` y busca el bloque `PRECIOS Y REGLAS` al inicio
del script. Ahí se editan los servicios y los canales de entrega.

## Cómo usarlo

Abre `index.html` en cualquier navegador. No necesita instalación ni servidor.

## Tecnología

HTML, CSS y JavaScript en un solo archivo, sin librerías externas.
